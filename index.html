Professional Self-Assessment

Throughout my journey in the Computer Science program at Southern New Hampshire University, I have gained the technical knowledge, professional skills, and practical experience needed to enter the field with confidence. Completing the coursework and developing my ePortfolio allowed me to showcase the strengths I have built across the program, refine my professional goals, and demonstrate my readiness for real-world software engineering roles. This self-assessment summarizes my growth, the skills I have strengthened, and how the artifacts included in this portfolio represent my abilities as a well-rounded computer scientist.

The ePortfolio has served as a valuable reflection of my progression—from learning foundational programming concepts to designing complex systems, implementing databases, building full-stack applications, and applying algorithmic solutions. Through each project, I learned not only how to write code, but also how to think critically about system design, security, maintainability, and usability. Preparing this portfolio has reinforced the importance of clear communication, professional presentation, and measurable demonstrations of technical competence, all of which are essential to advancing my career in software development.

A major part of my growth in this program involved collaborating in team environments. Courses such as Full Stack Development (CS-465) required coordination with peers, version control collaboration, and understanding diverse perspectives to support shared project goals. These experiences taught me how to participate in technical discussions, manage tasks collaboratively, and provide meaningful feedback during peer reviews. Collaboration has become a core strength that I will apply in agile development settings and cross-functional teams.

Effective communication with stakeholders was also emphasized throughout the program. Whether documenting code, preparing visual dashboards, developing UI components, or presenting a technical walkthrough, I learned how to explain complex concepts clearly and adapt my message to different audiences. The code review video completed for the capstone project helped refine my ability to articulate design decisions, identify improvement opportunities, and communicate enhancement plans in a professional and organized manner—skills that are essential for interacting with clients, managers, and technical teams.

My work with data structures and algorithms strengthened my ability to build efficient, scalable solutions. Courses such as CS-260 and CS-370 reinforced algorithmic problem solving, state management, and performance considerations. These experiences taught me how to evaluate trade-offs in design choices, optimize processes, and think analytically when approaching complex tasks. The reinforcement learning project helped me understand how algorithms drive intelligent decision-making systems.

In the area of software engineering and databases, I gained experience building modular applications, designing APIs, implementing CRUD operations, and integrating front-end and back-end components. Working extensively with MongoDB, Python, Express.js, Angular, and RESTful services helped me develop strong practical skills in full-stack development. I also learned how to adopt industry best practices such as separation of concerns, validation, error handling, logging, and documentation to create maintainable and production-ready systems.

Security was emphasized throughout the curriculum, which helped me develop a strong security mindset. I learned to identify vulnerabilities, validate data, handle exceptions safely, and apply principles such as least privilege and defense in depth. In database-driven and API-based projects, I learned how to protect data integrity and anticipate potential misuse. This perspective has shaped the way I approach software design and has prepared me to build more resilient and secure systems.

The three artifacts included in this ePortfolio—my full-stack Travlr Getaways application, reinforcement learning intelligent agent, and MongoDB dashboard with secure CRUD operations—represent the full range of my computer science abilities. Together, they demonstrate my proficiency in software engineering, algorithms, data structures, databases, system design, and secure development practices. Each artifact highlights a different aspect of my growth, and collectively they show my ability to design, build, enhance, and communicate complex technical solutions.

Overall, the process of completing my degree and assembling this ePortfolio has strengthened my technical abilities, improved my professional communication, and prepared me to enter the computer science field as a capable and confident developer. I am proud of the work represented here, and I look forward to applying these skills as I take the next steps in my career. My experiences throughout this program have shaped not only my technical expertise but also my professional identity, and I am now ready to contribute meaningfully to future software engineering and technology-driven projects.

Software Design and Engineering

Travlr Getaways – Full-Stack Web Application (CS-465)

Travlr Getaways is a full-stack travel booking web application developed as part of the CS-465 Full Stack Development course. The application includes a customer-facing website rendered using Express and EJS, as well as an Angular-based administrative interface that supports full CRUD operations.

This artifact demonstrates core software design and engineering principles, including modular architecture, backend API development, authentication, routing, and full-stack integration between frontend and backend components.

This artifact is an intelligent agent developed in CS-370 that uses reinforcement learning techniques to navigate a maze environment and optimize decision-making through experience. The project emphasizes algorithmic problem solving, state representation, and reward-based learning.

This enhancement demonstrates my ability to apply algorithms and data structures to solve complex problems, including managing state transitions, action selection, and experience replay to improve learning efficiency.

Grazioso Animal Shelter Dashboard – MongoDB & JupyterDash (CS-340)

This artifact is a data-driven dashboard developed using MongoDB, PyMongo, and JupyterDash to support data analysis for the Grazioso Animal Shelter. It includes secure database connection handling, CRUD functionality, advanced aggregation pipelines, and interactive data visualization.

This enhancement demonstrates my ability to design and implement robust database-driven applications, apply data aggregation techniques, manage secure database interactions, and present results through an interactive front-end dashboard.

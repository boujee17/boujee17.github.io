Travlr Getaways – Full-Stack Web Application (CS-465)

Travlr Getaways is a full-stack travel booking web application developed as part of the CS-465 Full Stack Development course. The application includes a customer-facing website rendered using Express and EJS, as well as an Angular-based administrative interface that supports full CRUD operations.

This artifact demonstrates core software design and engineering principles, including modular architecture, backend API development, authentication, routing, and full-stack integration between frontend and backend components.

Grazioso Animal Shelter Dashboard – MongoDB & JupyterDash (CS-340)

This artifact is a data-driven dashboard developed using MongoDB, PyMongo, and JupyterDash to support data analysis for the Grazioso Animal Shelter. It includes secure database connection handling, CRUD functionality, advanced aggregation pipelines, and interactive data visualization.

This enhancement demonstrates my ability to design and implement robust database-driven applications, apply data aggregation techniques, manage secure database interactions, and present results through an interactive front-end dashboard.
